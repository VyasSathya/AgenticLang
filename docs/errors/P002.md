# P002: Expected Token Not Found

## Description

The parser expected a specific token (like `;`, `)`, `}`) but found something else.

## Common Causes

1. **Missing semicolon**: Forgot to end a statement with `;`
2. **Unmatched delimiter**: Opened `(` or `{` but didn't close it
3. **Typo in keyword**: Misspelled a keyword like `func` or `return`

## Examples

### Missing Semicolon

```agentic
func calculate(x: number) {
  let result = x * 2  // ❌ Missing semicolon
  return result
}
```

**Fix:**

```agentic
func calculate(x: number) {
  let result = x * 2;  // ✓ Added semicolon
  return result;
}
```

### Unmatched Parenthesis

```agentic
func greet(name: string {  // ❌ Missing closing )
  return "Hello " + name
}
```

**Fix:**

```agentic
func greet(name: string) {  // ✓ Added closing )
  return "Hello " + name;
}
```
