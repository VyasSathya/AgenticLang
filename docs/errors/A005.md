# A005: Low Confidence Warning

## Description

The function has a confidence level below the recommended threshold (0.80). This indicates the code may need review or additional testing.

## Common Causes

1. **Complex logic**: The function implements complicated algorithms
2. **Edge cases**: Not all inputs are well-tested
3. **External dependencies**: Relies on uncertain external systems
4. **New code**: Recently written without extensive validation

## Examples

### Low Confidence Function

```agentic
@confidence(0.60)  // ⚠️ Below threshold
func parseComplexDate(input: string) -> Result<Date, ParseError> {
  // Complex parsing logic with many formats
  // Not all edge cases tested
}
```

**Solutions:**

1. **Add `@uncertain` explanation:**

```agentic
@confidence(0.60)
@uncertain("Multiple date formats possible, not all combinations tested")
func parseComplexDate(input: string) -> Result<Date, ParseError> {
  // ...
}
```

2. **Add property tests to increase confidence:**

```agentic
@confidence(0.85)  // ✓ Increased after testing
@property("handles ISO 8601 dates")
@property("handles US format MM/DD/YYYY")
@property("rejects invalid dates")
func parseComplexDate(input: string) -> Result<Date, ParseError> {
  // Same implementation, but now well-tested
}
```

3. **Break into simpler functions:**

```agentic
@confidence(0.95)
func parseISODate(input: string) -> Result<Date, ParseError> {
  // Simple, well-understood format
}

@confidence(0.95)
func parseUSDate(input: string) -> Result<Date, ParseError> {
  // Simple, well-understood format
}

@confidence(0.85)
func parseComplexDate(input: string) -> Result<Date, ParseError> {
  // Try each parser in sequence
  return parseISODate(input) or parseUSDate(input);
}
```

## Increasing Confidence

1. **Add property-based tests** - Test with random inputs
2. **Add unit tests** - Cover edge cases explicitly
3. **Get code review** - Have another developer validate
4. **Simplify logic** - Break complex functions into smaller parts
5. **Add documentation** - Explain assumptions and limitations

## Confidence Score Guide

- **0.95 - 1.00**: Thoroughly tested, well-understood, production-ready
- **0.85 - 0.95**: Good coverage, minor edge cases remain
- **0.70 - 0.85**: Basic testing, known limitations documented
- **0.50 - 0.70**: Experimental, needs review before production
- **Below 0.50**: Prototype only, significant work needed
